# Como contribuir

Leia o README e as decisões antes de iniciar uma tarefa. Este projeto usa recursos próprios do grupo e da conta pessoal do proprietário.

## Fluxo de trabalho

1. Escolha uma tarefa e combine responsável, revisor e critério de aceite.
2. Crie uma branch curta, por exemplo `feat/consulta-trajeto` ou `docs/revisao-escopo`.
3. Faça alterações pequenas e commits descritivos.
4. Abra um pull request com objetivo, comportamento e forma de verificação.
5. Peça revisão de outro integrante e resolva os comentários antes de integrar à `main`.

Não versionar senhas, tokens, arquivos `.env`, respostas identificáveis da pesquisa ou dados reais de passageiros. Usar `.env.example` apenas com nomes de variáveis e valores fictícios quando a stack estiver definida.

Não assumir que proteção de branch, CI, colaboradores ou serviços já estão configurados. Esses recursos serão preparados quando houver autenticação e responsáveis definidos. Os comandos de execução e testes da base inicial estão em [08-execucao-local.md](08-execucao-local.md).

## Revisão

Conferir o critério de aceite, permissões no servidor, estados de erro, visualização em celular, fonte e data das informações e documentação afetada. Usar cenários significativos; documentação deve ter links e números revisados.
